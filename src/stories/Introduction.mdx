# Reverb component workshop

Reverb is a genre-reactive music player built with Next.js, Redux Toolkit, D3 and
[shadcn/ui](https://ui.shadcn.com) (Base UI primitives + Tailwind CSS v4).

Every story renders inside an isolated Redux store preloaded with the demo catalog and
twelve weeks of seeded listening history. Use the **Theme** toolbar to switch between
dark and light.

- **Primitives** – shadcn/ui components themed with Reverb's tokens
- **Tracks** – rows, cards and the like button, all wired to Redux
- **Player** – transport controls and the docked player bar
- **Visualizer** – generative cover art and the D3 audio visualiser in each genre mode
- **Charts** – the D3 stats dashboard: donut, heatmap, force graph and radial clock
